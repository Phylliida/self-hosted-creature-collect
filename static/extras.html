✨ Extras workbench

Load your save, edit in any tool, then Save — everything else in the save passes through untouched.
Load pulls your newest server save and merges its extras data (anki decks, drawings, songs, fractals, todos…) into this browser. Save round-trips the same save with your edits — creatures, eggs and settings ride along unchanged. Heads-up: this browser keeps the merged data locally, so on a shared PC, loading two different trainers will cross-merge their extras.
